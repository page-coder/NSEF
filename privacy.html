Privacy and transparency

The public demonstration currently does not send or store form submissions.

Current configuration

Until a backend is configured, the feedback form displays a setup message and no message content is transmitted. Therefore there is currently no retention period, processor, or administrator access to describe.

Before collection is enabled

The site owner must publish an updated notice naming the chosen service, collected fields, purpose, access controls, actual retention period, deletion request method, and confidentiality limits. Optional reply email should only be used to respond to a request. Do not submit sensitive personal information.

Access and deletion

Once collection is live, this page must specify a contact route for deletion requests and who may access submissions. The required configuration is documented in the repository README.
